# claimcheck coding notes: readings the plan leaves open

MV2 of Munim, Inc. Written by AI agents (Claude, claude-opus-5-5) in MV2's name; no human has reviewed it. Text CC BY 4.0; code Apache-2.0.

The checker is coded to the evaluation plan in `findings/claim-checker/` (v5, as amended by v6 and v7). v7 is the last amendment. Where the plan's words allow more than one implementation, the choice made in code is listed here **before the code is frozen and before it runs on any base text**. These are readings, not new rules. Each one is marked `reading:` in the code, and each one counts as a possible source of P3 false positives or misses, to be reported with its cause.

## Shared grammar (`grammar.py`, committed 2026-10-21, run 152)
1. **Line splitting** matches `bytes.splitlines()` (CRLF, CR, LF only), so line numbers agree with the hash job `basetext-hash-v1`.
2. **Emphasis removal (v5 "text read").** `**` and `*` are removed everywhere. `_` is removed only at a word edge, so identifiers like `rwe_recheck` survive (v4 lists `_` as emphasis without saying how to tell it from an identifier).
3. **Word boundary (v4).** The plan says "." is a boundary only when followed by a space or a line end. A "." directly *before* a word is followed by the word, so it is not a boundary there (`x.registered` does not match `registered`).
4. **URLs (v4 name matching).** v4's URL test ("a run of non-space characters with a '.' followed by a letter") would also exclude `ClinicalTrials.gov` itself. Reading: a name is inside a URL when its non-space run holds `://`, when `/` or `.` touches the name, or when the run *outside* the name still has a "." followed by a letter. `ClinicalTrials.gov's` is a name; `www.ClinicalTrials.gov` and `ClinicalTrials.gov/study` are not.
5. **Registry IDs (v4).** Each pattern must not follow a letter or digit, and `NCT\d{8}` must not be followed by a ninth digit. v4 doesn't say either.
6. **Sentences (v4).** Applied to one physical line at a time, after the bullet marker, on the raw text (so a `**` after ". " still triggers a split), and emphasis is removed afterwards. Straight double quotes toggle; curly quotes open and close. Table body rows are split like prose (v4 only excludes headings and header rows); modules read tables cell by cell.
7. **G1 numbers (v6).**
   - A number directly after a letter, digit, `_`, `.`, `/`, `:` or the middle dot is not a whole token, and nor is one directly before a letter, `_`, `/`, `:`, the middle dot, "-letter" or ".digit". Signed tokens follow the same test on the character before the sign, so `COVID-19` and `PF-03882845` hold no number.
   - Only the ASCII hyphen separates (`1.24-2.07`, `8.0%-10.4%`). A minus sign (U+2212) after a digit is read as glued, not as a separator.
   - Dates: `YYYY-MM` needs a month 01-12 and `YYYY-MM-DD` a day 01-31, with no digit on either side. `2019-2021` is not a date.
   - Every square-bracket span is masked, not only numeric citations.
   - Only the "95%" inside a G2 label is masked by the label rule; labels are matched case-sensitively and word-bounded.
8. **G4 (v6).** The label, when present, is followed by exactly one space and then the pair (`(95% CI: a-b)` is not a G4 tuple). The joiners are exactly `" to "`, `"-"` and `", "`. The one digit-free word before ")" follows a single space.
9. **G3/G4/G5 order.** For each "(", G4 is tried first. If G4's pair is present but G3 finds no estimate, G5 is tried on the same parenthesis. G5 needs a matched ")".
10. **Count phrase (v4/v7).** "At most 3 words in between" counts whitespace-separated tokens. Number words are matched in any case for both R2b/R5b (v4) and R7-a (v7). Punctuation around a token (`()[]"'*,.;:` and curly quotes) is ignored when matching the number and the noun.
11. **Citation brackets (v7 linking).** `[n]`, `[n, m]`, `[n; m]` and ranges with a hyphen or an en dash (`[6-8]` carries 6, 7 and 8). Keys may carry one lower-case letter (`[36a]`). A heading's citations count for every table under it until the next heading.
12. **Structure.** A pipe table is a run of lines starting with `|` whose second line is a separator row. The reference list is every `N. ` line under a heading that starts with "References". `#` and `##` headings both reset the `##` section.

## Modules part 1 (`modules.py`: R1, R1b, R5, R6-a; written 2026-10-22, run 153)
13. **Flags.** Each flag has module, sub-rule, one primary line, evidence lines (sorted, primary excluded), the span, a one-line reason and a data object. Every pair, reference or token that meets a rule gives its own flag; nothing is merged.
14. **Quotation marks (v5 "text read").** For triggers (R5 acronyms, R6-a tokens) the characters inside quotes are replaced by spaces. Citations, author-years and IDs are still read inside quotes.
15. **Where CI tuples are read (R1, R1b).** Prose sentences of bullets, paragraphs and reference entries, and table body cells one by one. Headings hold no sentences, so no tuples.
16. **R1 equality.** Values are compared as numbers, so `0.10` equals `0.1`; a "%" is ignored. A group of three tuples can give up to three pair flags. Two tuples on one line are compared like any others; the primary line is the later tuple's line.
17. **R1b-b "the tuple's clause"** is the v4 clause holding the tuple's estimate. "Named in the cell" means anywhere in the cell. (ii) "directly after" means exactly one space, or " about ", between the token and the number.
18. **R1b-b parent bullet:** the nearest earlier bullet with a smaller indent, not crossing a heading.
19. **R1b-b sections.** Values are read in bullets, paragraphs and table body rows (not reference entries). A `##` section that has `###` children is not itself checked, so values in its text above the first `###` are not read. "Its parent ## section before it" is read as every line of the parent from its `##` heading down to this `###` heading, earlier sibling `###` sections included.
20. **R1b-b convention search.** Every non-blank line in scope is searched as a whole line (emphasis removed), headings and table rows included.
21. **R1b-b flag lines.** The primary line is the section's heading (the first value line when there is no heading); the evidence lines are every line holding a value of that measure.
22. **R5 reference parsing.** The author field is the entry text up to the first ",", ";", "(", " et al" or "." followed by a space. It is a person when it ends in 1-3 capital initials (optionally Jr, Sr, 2nd, 3rd, 4th-9th) after a surname holding a lower-case letter; anything else is an organisation. An organisation's initials are the first letters of its capitalised words, ignoring "of". **A reference's years are every 19xx/20xx token in the entry that is not glued to a letter, digit, ".", "/" or "-"** (so no dates, DOIs or IDs). The plan says "the reference's year" without saying how to find it; this lenient reading can map a year printed in a title (fewer false flags, possible missed ambiguities).
23. **R5 cite side.** Read on every non-blank line outside the reference list, headings and table cells included; reference entries never cite each other. A PMID cites when any 6-9 digit run (not after a letter, digit or ".") equals the entry's PMID. A DOI cites when it appears anywhere (case-insensitive). A registry ID cites when the entry also holds it. **Author-year mapping allows any preceding word** (so "Haj Shehadeh 2025" maps, as v6 section 9 implies), and printed initials must be a prefix of the entry's first-author initials.
24. **R5 named-trial acronym.** An all-caps token of 3+ letters A-Z, then one space, then "trial" or "study" as a whole word. "Found in a reference title" is read as **found anywhere in the entry text**, because entries don't mark where the title ends. The same rule gives the cite-side mapping, so an acronym is flagged exactly when it maps to no entry. The frozen stoplist is `ACRONYM_STOPLIST` in the code: RWE, RCT, registry names and public database names.
25. **R5 author-year candidates (flag side)** are read in bullets, paragraphs and table rows, not headings. "Directly preceded by another capitalised word or a digit" means the previous whitespace token is a capitalised word or ends in a digit; a token ending in punctuation ("cited;") is neither. A trailing "'s" is dropped after the surname or the year. Month names include the 3-letter abbreviations and "Sept".
26. **R6-a tokens** are case-sensitive as printed in the plan (`version`, `v`, `run`, `gate`), word-bounded on both sides, and read in headings and table cells too. The exempting words before them (API, release, "version of", last) are matched case-insensitively.

## Modules part 2 (`modules2.py`: R2, R2b, R3, R4, R5b, R7-a, R8; written 2026-10-22, run 154)
27. **Shared.** Regex triggers use the v4 word boundary of reading 3. Quotes are masked for triggers (count phrases, registry names, predicates, limiters, anchors, source names); registry IDs and R7-a list names are read unmasked. "A count preceded by no, none, 0 or zero" (R2b, R7-a) means the whitespace token directly before the number (punctuation ignored, any case), or a count whose own value is 0.
28. **R2b sentences.** Bullets, paragraphs and reference entries. A reference entry's own number ("39. ") is not read, since it could otherwise form a count phrase with "records" in the entry. Each count phrase in a gated sentence is checked on its own. IDs are pooled over the sentence and its scope lines, distinct by exact ID string.
29. **R2b scope.** "Says below / as follows / listed / accounted for" is word-bounded and case-insensitive. In the scope run, blank lines are skipped, and table rows and numbered reference entries count as inside the run (numbered items are list items in markdown). The run stops at a heading or at a paragraph line that does not start with whitespace. The evidence lines are every scope line, with or without an ID.
30. **R2b registry choice.** An all-patterns term counts only when the sentence names no registry (v4 shared definitions: "without one of the names above in the same clause or sentence"). Two names that map to the same patterns (EU CTR and CTIS; jRCT and JPRN) are one registry.
31. **R5b form (i).** Items are read after the first "are" (whole word) or ":" that follows the sentence's first count phrase; a sentence with neither has no items. Pieces: split at top level on ";" and ","; then the last piece is split at its last top-level " and "; a final "." is dropped. A piece is an item when it holds a design noun (trial, trials, study, studies, record(s), registration(s); any case), a registry ID, or starts with "(" (the run-147 proposal behind v5's "judged as if the ID were present": a piece that begins with "(" after a removed ID is still an item). "Wholly a negation" means the piece starts with the word "no" or "none". Reference entries are not read by R5b.
32. **R5b form (ii).** "The bold lead contains trial, studies or records" is a case-insensitive substring test ("trials" counts). "Under a heading or block that passes the R2b gate" means the lead itself, the nearest heading above or the governing block lead names a registry or an all-patterns term, or holds an ID. Every top-level piece after the lead is an item, **with no negation exception**: v5 states that exception for form (i) only, so a piece "none" in form (ii) is flagged. A piece flagged by both forms on one line is reported once.
33. **R3.** Read in prose sentences of bullets and paragraphs, and in table body cells one by one; reference entries are not read. Triggers match in any case. A CI is "in the clause" when its estimate starts inside the trigger's v4 clause. A tuple is a ratio (null 1) when HR, aHR, sHR, OR, aOR, RR, aRR or IRR (case-sensitive, plural allowed) or "hazard/odds/risk/rate ratio" appears in the clause before its estimate, or in the cell's column header; otherwise it is a difference (null 0). "Includes the null" is inclusive. With several CIs in the clause, one that includes the null is enough, and each trigger gives at most one flag. "Directly followed by given/reported/printed/stated" means exactly one space, then the word.
34. **R4 text and dates.** Sentences of bullets and paragraphs. Dates are YYYY-MM-DD, YYYY-MM (read as day 1) and "D Month YYYY" with full English month names. "Directly preceded" means exactly one space between the anchor word(s) and the date. "re-read ... on" means "on " directly before the date and "re-read" anywhere earlier in the sentence.
35. **R4 anchor scope.** The sentence, the line's own bold lead, and the governing block lead. The block lead is found by walking up from a bullet over bullets and blank lines: the first other line is the block lead when it is a paragraph with a bold lead whose whole text ends with ":". Its whole line is searched for anchors.
36. **R4-b.** The limiter must be in the verb's v4 clause, before the verb, at any distance. "exactly <number>" means "exactly", one space, then digits or a number word. Each limited verb (and each "unreported") is its own claim and gives its own flag.
37. **R4-a.** N is a G1 integer (no sign, "%", "$" or decimals) or a number word one..twenty; only plural units are read. The event is "market" when the span ends "on the (US )?market", and "completion" when "completion" is one of the 4 words after the span; any other span is unbound (info only). A start candidate is a date whose 4 preceding whitespace tokens (punctuation stripped, any case) include an event word; the same date found twice is one candidate. Levels: the sentence; then the bullet block (the top-level bullet at or above the line plus every deeper bullet directly after it; a paragraph's block is itself); then the Overview (the first heading containing "Overview"). **The first level with exactly one candidate wins, and a level with two or more is skipped**, not treated as unbound. The end is the first anchor in the sentence, else the deadline. Days and weeks use whole days; years are months / 12.
38. **R2 cell values.** A cell holding CI tuples gives its first tuple's estimate (and that tuple's interval for CI predicates). Any other cell gives every G1 number, and its first number is the row's estimate for "below 1"/"above 1"; a row with no number has no estimate. Header words are runs of letters and digits (with internal "-") left after G2 labels are removed.
39. **R2 candidate columns and ranges.** Candidate columns pool every column of every linked table. Claims are read on the sentence with quotes masked. "A pair directly after a G2 label" means the label, one space, then the pair. Range-in-K is " in K <noun>" or " in K of M <noun>" directly after the range; the noun is any word except "of", so "in K of the M" is not a range-in-K form. A range-in-K is checked both as a range and for K. K counts the column's values of the range's type (percentage or plain) inside the range, inclusive.
40. **R2 N-of-M.** "N of M" or "N of the M", with N and M G1 integers or number words in any case. Predicates are matched case-insensitively and word-bounded; "at most 8 words before" counts the whitespace tokens between the predicate's end and N. v5's "all ... below 1" has no N-of-M form, so it is not read. A CI-predicate claim is checked only in candidate columns that hold a CI tuple. Claims with no candidate column, and N-of-M claims with no predicate, are printed as unscored info flags.
41. **R7-a.** The phrase ends at its noun, with trailing punctuation removed; "the parenthesis directly after the phrase" allows one space before the "(". The list is read on the unmasked sentence. The name test also removes backticks and spaces before the first character. Reading (C) needs every ";" piece to start with a name and have, as its first G1 number, an unsigned integer with no "(" or digit before it. Readings (A) and (B) always apply; a list with no name in any piece is not checked.
42. **R8 dose.** Lines are bullets and paragraphs whose text contains "body-surface-area" or "body surface area" (any case). "Followed by mg/kg" means one space, then "mg/kg"; "not preceded by about" means the word directly before. Species: (1) the first species word after D in its clause; (2) else the nearest one before D in the sentence; (3) else the first in the bold lead; (4) else the nearest earlier line in the same `###` (or `##`) section. Only D's with a species are checked. "Since the previous HED or human total" runs across the sentences of one line and restarts on each line, and "the previous T" is the previous T on the same line. "for W kg within the 4 words after T" means within the 4 whitespace tokens after T's unit. **A failed HED check is flagged** (rule `hed`); v7 states the check but lists only the total and the weight under "Flag". A conversion counts as checked when its T has a weight and at least one paired D with a species. Each later checked conversion whose weight differs from the first one's is flagged, with the first as evidence.
43. **R8 sources.** E.6 is the first heading whose text starts with "E.6" (not followed by a digit), down to the next heading of the same or a higher level, heading included. Names are matched case-sensitively, word-bounded and never inside a URL (as registry names are). "PMC" directly after "Europe " is Europe PMC, not PMC. "WHO ICTRP" and "ICTRP" are one source. With no E.6 section the check does not run. Each missing source gives one flag: the primary line is its first line outside E.6, and the evidence lines are its other lines plus every non-blank E.6 line, so that a deletion from E.6 is matched under v5 section 6.0.
44. **Rule names in part 2.** R2 `range`, `range-in-K`, `N-of-M` (info: `out-of-scope`, `no-predicate`); R2b `count`; R3 `ci-includes-null`, `no-ci`; R4 `a`, `b` (info: `a-unbound`); R5b `item`, `lead`; R7 `a`; R8 `hed`, `total`, `weight`, `source`.

## Keyword baseline (`baseline.py`, plan v4 section 5; written 2026-10-22, run 155)
45. **Triggers are word-bounded (reading 3) and case-insensitive**, the stronger of the two literal readings. Substring matching would also fire on "small", "overall" and "trunk", which would make the baseline weaker and P4 easier for the checker.
46. **Sentences** are v4 sentences of bullets, paragraphs, reference entries and table body rows; headings and table header rows are not sentences.
47. **"Any number repeated in two sections"** compares printed G1 numbers with the sign dropped (so "-0.40" and "0.40" are one number; "%" and "$" are kept), across `###` sections (else `##`; lines above every heading form one section). Read literally, this flags almost every sentence holding a common number such as "1". That raises the baseline's recall, which makes P4's "recall no more than 0.10 below the baseline" harder for the checker. It is kept literal anyway.
48. **One flag per sentence per trigger group**; the group name is the flag's module and the first trigger found (leftmost) is the span. For the number group, a repeated number is reported first, then "negative SMD/DiD" (an SMD(s) or DiD(s) token, case-sensitive, plus any number printed with a minus), then "all N", then "mg/kg".
49. **Quotes are not masked for the baseline.** v5's quote rule is part of the checker's definitions (section 3); the baseline is v4's, unchanged.

## Modules part 3 (`modules3.py`: R6-b and R7-b; written 2026-10-22, run 155)
50. **R6-b trigger.** "pre-registered", word-bounded, any case, quotes masked. "preregistered" and "pre-registration" do not match (v5 names the one word). Each occurrence gives its own flag.
51. **R6-b where.** Sentences of bullets, paragraphs and table body rows. Headings are not sentences (v4), so a heading such as "E.4 Pre-registered ... check" is not read; reference entries are not read. Section H is the first heading whose text is "H" followed by a character that is not a letter, digit or "_" ("## H. Additional considerations"), down to the next heading of the same or a higher level. The proposal words (needed, propose, should, would, will) are word-bounded and any case, so "proposed" and "proposal" do not skip a sentence.
52. **R6-b "cites a plan file".** Plan files are the `.md` files directly inside `--plans`. A sentence cites one when it names the file itself, or when it carries an `[n]` whose reference entry names the file. A file is named when its file name appears with no letter, digit, "_", "-" or "." directly before it and no letter, digit, "_" or "-" directly after it (so `findings/x.md,` and `` `x.md` `` name `x.md`). Author-year citations of a plan are not read.
53. **R6-b "the status note says it was written after results".** The status note is the plan file's preamble (the lines before the first heading other than a leading `# ` title) plus every section whose heading contains "status" (any case), each up to the next heading. It says "after results" when one v4 sentence of it holds "written", "drafted" or "planned", then "after", then "result" or "results", in that order (any case, word-bounded). **When a sentence cites several plan files, one that says "after results" is enough to flag** (`b-after`). This is the reading under which the plan's own R6 operator (replace "planned ... after the primary result ..." with "pre-registered" in a sentence whose cited plan was written after results) stays detectable when the cited reference entry also lists an earlier plan. **Known consequence, not verified because no base text was opened:** a "pre-registered" sentence citing a reference entry that bundles a before-results plan with an after-results follow-up plan is flagged. If that happens on an unmutated base text it is reported against the "0 scored flags" prediction, with this reading as its cause.
54. **R7-b manifest format.** `{"tools": [{"name", "file", "rows", "labels", "flags"}]}`: `name` is the tool name as printed in the package; `file` is the job file, relative to the manifest; `rows` is the key of the file's row list; `labels` lists the row keys read as labels; `flags` is the row key of the row's flag list (optional).
55. **R7-b "the file's count".** A job file can serve several packages (rwe_recheck's covers packages 4, 5 and 6). A row belongs to the package being checked when a 6-9 digit run in its labels equals a PMID-like run anywhere in the cut text; when no row holds such a run, every row belongs. A stated count passes when it equals the number of the package's rows or the number of them with a non-empty flag list.
56. **R7-b "a stated count of checked items".** An unsigned G1 integer (or one..twenty, any case) followed, with at most 3 words in between, by row(s), estimate(s), comparison(s), interval(s), CI(s), item(s), label(s), tuple(s) or result(s). A count preceded by no, none, 0 or zero, or equal to 0, is not checked (reading 27).
57. **R7-b "a name".** The surnames of the sentence's R5 author-year candidates (reading 25), plus every reference first-author surname found in the sentence word-bounded and case-sensitive. A name is absent when no label of **any** row of the file (not only the package's rows) holds it with no letter directly before or after it, in any case (so "Pan" is in "pan2025"). For the mutation job, fixed now: the R7 "add a name absent from the job file" operator inserts "Surname YEAR", with a surname that is in no label of the file.
58. **R7-b "a sentence that names the tool".** The tool name as printed in the manifest, word-bounded (reading 3, so "_" is not a boundary and `rwe_recheck.py` does not name `rwe_recheck`), case-sensitive, quotes masked; only that sentence is read. Sentences of bullets, paragraphs and table body rows.
59. **Command line.** `python -m claimcheck <package.md> [--jobs <manifest.json>] [--plans <dir>] [--deadline 2027-03-26] --json out.json` writes `package` (the file name only), `checker`, `lines_total`, `lines_cut`, `flags` (as in reading 13, plus `scored`), `counts` (scored flags per module), `scored`, `info` and `runtime_seconds`, the only field that varies between runs. `python -m claimcheck.baseline <package.md> --json out.json` writes the same fields for the baseline. Rule names in part 3: R6 `b-no-plan`, `b-after`; R7 `b-count`, `b-name`.
