## What the package holds (format only)

The open KPMP "Seg_Masks_Features" (v2) package for a biopsy slide contains:

- the slide (`.svs`, Aperio, PAS);
- a multilayer pyramidal OME-TIFF annotation file (axes CYX, unsigned 16-bit, 6 pyramid levels, each halving the
  previous). Its 7 channels are named in the OME-XML: cortex, non-globally-sclerotic glomeruli,
  globally-sclerotic glomeruli, tubules, arteries/arterioles, peritubular-capillaries, IFTA. The package README
  says each segmented unit in a layer is a unique integer. The mask's level-0 width and height equal the slide's;
  the OME-XML gives the pixel-size unit but no pixel-size value;
- the same OME-XML as a separate file;
- an Excel feature workbook with sheets `gloms`, `s_gloms`, `tubs` and `arts` (one row per object, bounding box
  and measurements; the README says v2 measurements are in pixels);
- a README describing the segmentation (a Detectron2 panoptic model, quality-controlled by a renal pathologist).

So KPMP's glomeruli can be counted per class from the label mask, and their areas put in um^2 through the slide's
own pixel size. This makes the stage-3 plan binding (it required D1 and D4); the mask-reading rules are fixed in
`findings/kidney-glom-compare-plan-v0-addendum-2-2026-11-09.md`, published with this note and before any graded
slide is processed.
